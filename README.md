# 🪔 Mehta Family Diwali Greeting 🪔

A premium, cinematic, mobile-responsive family Diwali greeting web application featuring the real illuminated Mehta residence, animated celebration intro, festive soundtrack, interactive diyas, fireworks, and WhatsApp greeting sharing.

## ✨ Features

- **🏠 Real House Photograph**: Features the Mehta Family home illuminated with Diwali lights as the hero background with Ken Burns cinematic zoom and warm lighting effects.
- **🎬 Cinematic Animated Intro**:
  - Chaptered animated sequence with realistic sound effects:
    1. Sacred Diya ignition with match strike & flame flare.
    2. Blooming and rotating golden sacred Rangoli mandala.
    3. Floating sky lanterns (kandils) rising into the night sky.
    4. Grand firework bursts and confetti celebration.
  - Seamlessly unlocks the single-page family greeting.
- **🎵 Festive Celebration Soundtrack**: Traditional Indian celebration track featuring sitar, shehnai, dholak rhythms, and festive melodies (`/audio/bed.mp3`) with sticky play/pause/mute controls.
- **📜 Sacred Hindi Blessing & Wishes**:
  > *"दीपों की जगमगाहट आपके जीवन को खुशियों से रोशन करे, माँ लक्ष्मी की कृपा से घर में सुख, शांति और समृद्धि बनी रहे। आपके हर सपने को नई उड़ान मिले और हर दिन खुशियों से भरा रहे। आप सभी को दीपावली की हार्दिक शुभकामनाएँ!"*
- **👨‍👩‍👦‍👦 Mehta Family Names Section**:
  - GAUTAM – MAMTA
  - YASH – SUDHI
  - NAVNEET
  - VAIBHAV
  - DAKSH
  - MEHTA FAMILY
- **🪔 Interactive Diya Lighting Altar**: Tap to light 5 individual clay diyas (*शुभ, लाभ, स्वास्थ्य, शांति, समृद्धि*) with bell chimes and flickering flames.
- **🎆 60fps Canvas Fireworks**: Tap/click anywhere on screen to burst fireworks.
- **📱 WhatsApp Sharing**: One-click sharing with pre-filled personalized Hindi message and copy link functionality.
- **📱 100% Mobile Responsive**: Tested on modern iOS and Android viewports (`100dvh`, zero overflow).

## 🚀 Tech Stack

- **React 19** + **Vite**
- **Tailwind CSS v4**
- **Framer Motion**
- **Canvas-Confetti**
- **Lucide React Icons**
- **Web Audio API & HTML5 Audio**

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Vaibhavmehta9/diwali-wishis.git

# Navigate to project directory
cd diwali-wishis

# Install dependencies
npm install

# Start development server
npm run dev
```
